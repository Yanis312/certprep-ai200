# Introduction — choisir, déployer, évaluer un modèle

## L'essentiel

- Une bonne application d'IA générative commence par le **bon modèle de fondation** pour ton cas d'usage.
- Le catalogue Foundry propose **plus de 1 900 modèles** (Microsoft, Anthropic, OpenAI, Meta, Hugging Face...). Il faut une méthode.
- Le portail Foundry couvre tout le parcours en **4 étapes** : explorer, comparer, déployer, évaluer.

## Le parcours en 4 étapes

```
1. EXPLORER        2. COMPARER          3. DÉPLOYER           4. ÉVALUER
catalogue    →     benchmarks     →     endpoint        →     métriques
de modèles         qualité              + playground          automatiques
filtres            sécurité                                   + tests manuels
                   coût
                   performance
```

| Étape | Question à laquelle elle répond | Unité |
|---|---|---|
| Explorer | Quels modèles existent pour mon besoin ? | Explore the model catalog |
| Comparer | Lequel est le meilleur compromis ? | Select models using benchmarks |
| Déployer | Comment mon application y accède-t-elle ? | Deploy models to endpoints |
| Évaluer | Répond-il vraiment bien et sans danger ? | Evaluate model performance |

## Le scénario fil rouge

Tu construis un **chatbot de support client** pour une enseigne de vente au détail. Le modèle doit :

- comprendre les questions des clients ;
- donner des réponses **exactes** ;
- garder un **ton** adapté ;
- respecter les exigences de **sécurité**.

Les trois questions du module : comment choisir parmi des milliers de modèles ? Comment savoir s'il convient à **mon** besoin ? Une fois déployé, comment mesurer et améliorer ses performances ?

## Les 4 dimensions de comparaison

À retenir dès maintenant, elles reviennent partout : **qualité, sécurité, coût, performance**.

#### Point examen : l'examen attend que tu saches « choisir un modèle approprié pour chaque tâche » et « évaluer les modèles et les applications ». Ce module couvre les deux.
